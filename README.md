# Indian Railways Sign-Up Form

A responsive passenger registration form inspired by the Indian Railways (IRCTC) portal, built for **The Odin Project** Intermediate HTML & CSS curriculum.

## Live Demo
[View Live Project](https://narukanaveen.github.io/railway-signup-form/)

## Features
- **Flexbox Split-Screen Layout:** Full-height Vande Bharat Express hero sidebar paired with a structured registration card (built purely with CSS Flexbox).
- **HTML5 Constraint Validation:** Native validation (`required`, `minlength`, 10-digit `pattern`) styled dynamically using `:focus` and `:user-invalid` pseudo-classes.
- **External Form Trigger:** Submit button connected externally using the HTML5 `form` attribute.

## Tech Stack
- HTML5
- CSS3 (Flexbox)
